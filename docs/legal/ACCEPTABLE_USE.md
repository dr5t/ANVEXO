## 1. Purpose and Scope

This Acceptable Use Policy outlines the rules governing the use of ANVEXO. This policy applies to all users, operators, and organizations utilizing the ANVEXO CLI, API, or web interface.

## 2. Permitted Uses

ANVEXO is intended strictly for legitimate software engineering, quality assurance, system debugging, and authorized codebase investigation, including:

1. Diagnosing regressions, failures, and defects in codebases you own or are authorized to inspect.
2. Exploring architecture, dependencies, and git history for authorized software maintenance.
3. Conducting authorized code quality, security audits, and hypothesis testing in development or staging environments.
4. Generating evidence-backed reports and findings for internal engineering teams.

## 3. Prohibited Activities

You agree not to use ANVEXO to:

1. Unauthorized Inspection: Analyze, decompile, or execute tools against repositories or computer systems for which you have not received explicit written authorization from the system owner.
2. Malicious Code Development: Generate, refine, or optimize malware, spyware, ransomware, exploit payloads, or malicious automated attack tools.
3. Denial of Service and Resource Abuse: Overwhelm public or private infrastructure through unbounded parallel investigation processes, abusive model querying, or bypassing rate limit protections.
4. Security Boundary Tampering: Attempt to circumvent path containment checks, sandbox constraints, or permission enforcement layers to access unauthorized files outside the designated repository root.
5. Deceptive Attribution: Publish automated investigation findings, claims, or bug reports while falsely attributing authorship to third-party engineers or asserting verified statuses without evidence.

## 4. Enforcement and Violations

Failure to adhere to this policy may result in immediate revocation of software licenses, termination of support services, and referral to relevant law enforcement bodies where unlawful conduct is identified.
